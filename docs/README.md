## 更新方針

- 実装や検証フローを変更した場合は、関連するドキュメントも必要に応じて更新してください。
- ドキュメントに未実装の内容を書く場合は、現在の実装と将来方針を分けて記載してください。
- 既存の方針と異なる判断を追加する場合は、理由も併記してください。

## 検証

ドキュメントのみの変更でも、コードや設定に影響がある場合は次を実行してください。

```bash
npm run verify
```
