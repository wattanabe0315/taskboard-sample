# TODOアプリ機能仕様

## 目的

TaskBoard は、ユーザーが日々のTODOを追加・確認・完了・削除できるシンプルな TODO 管理アプリケーションです。

最初の実装では、個人がブラウザ上でタスクを整理できることを目的とします。
チーム共有、ログイン、サーバー保存などは MVP には含めません。

## 対象ユーザー

- 個人でTODOを管理したいユーザー
- 作業前にやることを短く書き出したいユーザー
- 完了したTODOを画面上で確認したいユーザー

## MVPスコープ

MVPでは、以下の機能を提供します。

- TODOを追加できる
- TODO一覧を表示できる
- TODOを完了済みにできる
- 完了済みTODOを未完了に戻せる
- TODOを削除できる
- 空文字のTODOを追加できない

## MVPで扱わないこと

以下は MVP では扱いません。
必要になった時点で、別途仕様を追加してください。

- ユーザーログイン
- 複数ユーザーでの共有
- サーバー保存
- 期限管理
- 優先度管理
- タグ管理
- 検索
- 並び替え
- フィルタリング
- TODOの編集
- 完了済みTODOの一括削除

## 主要概念

### TODO

ユーザーが管理する1つのタスクを表します。

| 項目 | 型 | 説明 |
| --- | --- | --- |
| `id` | string | TODOを一意に識別するID |
| `title` | string | TODOの本文 |
| `completed` | boolean | 完了済みかどうか |
| `createdAt` | string | 作成日時 |

## 画面仕様

### 初期表示

- TODO入力欄を表示する
- 追加ボタンを表示する
- TODOが存在しない場合は、空状態が分かる表示を行う

### TODO追加

- ユーザーは入力欄にTODOの本文を入力できる
- 追加ボタンを押すとTODOが一覧に追加される
- TODO追加後、入力欄は空になる
- 追加されたTODOは未完了状態になる

### TODO一覧

- TODOを作成順に表示する
- 各TODOには、本文、完了切り替え、削除操作を表示する
- 完了済みTODOは、未完了TODOと見た目で区別できる

### 完了切り替え

- 未完了TODOを完了済みに変更できる
- 完了済みTODOを未完了に戻せる
- 切り替え操作後、一覧上の表示が更新される

### TODO削除

- 各TODOを削除できる
- 削除したTODOは一覧から消える
- MVPでは削除確認ダイアログは表示しない

## バリデーション

- 空文字のTODOは追加できない
- 前後の空白は削除してから追加する
- 空白だけの入力は空文字として扱う
- TODO本文の最大文字数は100文字とする
- 最大文字数を超える入力は追加できない

## 状態管理

MVPでは、TODOの状態はブラウザ上のメモリで管理します。
ページを再読み込みした場合、TODOは保持されなくて構いません。

永続化が必要になった場合は、ブラウザストレージまたはAPI連携の仕様を追加してください。

## エラー表示

- 空文字のTODOを追加しようとした場合は、追加できないことをユーザーに伝える
- 最大文字数を超えた場合は、100文字以内で入力する必要があることをユーザーに伝える

## テスト観点

MVPでは、以下をテスト対象にしてください。

- 空のTODOを追加できない
- 前後の空白を削除してTODOを追加できる
- TODOを追加すると一覧に表示される
- 追加直後のTODOは未完了である
- TODOを完了済みにできる
- 完了済みTODOを未完了に戻せる
- TODOを削除できる
- 100文字を超えるTODOを追加できない
